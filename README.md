# NotaGoiana

Plugin do NotaGoiana, o sistema de emissão de NFS-e (nota fiscal de serviço) para empresas e escritórios de
contabilidade. Com ele, você consulta o faturamento, acha notas e tomadores, prepara, emite e cancela notas conversando,
nas empresas que você acessa e dentro do seu plano.

## Instalar

No Claude Code:

```
claude plugin marketplace add n8namigos/notagoiana-plugins
claude plugin install notagoiana@notagoiana
```

Depois rode `/mcp`, escolha `notagoiana` e autentique: abre a página do NotaGoiana, que mostra para onde a conexão vai.
Informe o e-mail com que você entra no sistema, digite o código de 6 dígitos que chegar e clique em "Permitir".

No claude.ai e no aplicativo, procure "NotaGoiana" em Configurações → Conectores.

## O que dá para pedir

- "Quanto a minha empresa faturou em outubro? Quais os 5 maiores clientes?"
- "Emite uma nota igual à do mês passado para o Condomínio Solar, com o valor de R$ 1.200,00."
- "Me dá o link da nota 154 para mandar ao cliente."

Tudo o que o assistente faz fica em Integrações → Conectar a IA → Histórico, e você desliga a conexão quando quiser.
